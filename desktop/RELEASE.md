## 다운로드

| 파일 | 누구에게 | 하는 법 |
| --- | --- | --- |
| **CrownOfTheDead-Setup.exe** | 윈도우 (추천) | 실행하면 바로 설치되고 게임이 켜집니다. 바탕화면과 시작 메뉴에 '망자의 왕관'이 생깁니다. |
| CrownOfTheDead-Portable.exe | 윈도우, 설치 없이 | 받은 파일을 그대로 실행합니다. 켤 때마다 몇 초 걸릴 수 있습니다. |
| CrownOfTheDead-Web.zip | 맥 · 리눅스 · 그 밖 | 압축을 풀고 index.html을 크롬·엣지·사파리로 엽니다. |
| CrownOfTheDead-x86_64.AppImage | 리눅스 | 실행 권한을 주고(`chmod +x`) 실행합니다. |

### "Windows의 PC 보호" 창이 뜨면
유료 코드 서명 인증서가 없는 프로그램이라 처음 실행할 때 경고가 뜹니다. **추가 정보 → 실행**을 누르면 됩니다.

### 저장
- 진행 상황은 층을 오갈 때, 마을에 들어올 때, 레벨업할 때, 그리고 창을 닫을 때 자동 저장됩니다.
- 윈도우 앱의 저장 위치: `%APPDATA%\Crown of the Dead` (게임을 지웠다 다시 깔아도 저장은 남습니다)

### 조작
왼쪽 클릭 이동·공격·줍기 · 1–6 / 오른쪽 클릭 기술 · Q 물약 · T 귀환 · I 소지품 · C 캐릭터 · K 기술 창 · Tab 지도 · Esc 메뉴 · **F11 전체 화면**
