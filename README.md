# 망자의 왕관 (Crown of the Dead) — 야만용사 핵앤슬래시

디아블로 2 스타일의 아이소메트릭(비스듬한 시점) 액션 RPG 프로토타입입니다.
야만용사로 국경 야영지 마을에서 장비를 갖추고, 끝없이 이어지는 지하 묘지를 내려가며 몬스터를 사냥합니다. 레벨업마다 기술 포인트를 받아 기술 창에서 원하는 기술을 골라 배우고, 떨어진 장비를 주워 착용하고, 모은 골드는 마을 상인에게 씁니다.

설치나 빌드 없이 브라우저만으로 실행됩니다. 캐릭터·몬스터·던전·마을 그림과 효과음은 무료 공개 자원인 [Flare 프로젝트](https://github.com/flareteam/flare-game)의 것(CC-BY-SA 3.0)을 씁니다.

## 실행 방법

- `index.html`을 브라우저(크롬, 엣지, 파이어폭스, 사파리)로 열면 바로 실행됩니다.
- 또는 로컬 서버로: `python3 -m http.server 8000` 실행 후 `http://localhost:8000` 접속

진행 상황은 브라우저 저장소에 자동 저장됩니다(층 이동, 마을 이동, 레벨업 시). 타이틀 화면의 **이어하기**로 계속할 수 있습니다. 보관함(4쪽 × 48칸 = 192칸)에 넣은 물건과 열린 웨이포인트도 저장됩니다.

### 소지품 다루기

| 입력 | 동작 |
| --- | --- |
| 아이템 누르기 | 자세한 정보와 버튼(착용 · 판매/버리기 · 옮기기) 보기 |
| Shift + 클릭 | 상인 창이 열려 있으면 바로 판매 (대장장이에게서 되살 수 있음), 보관함이 열려 있으면 넣기·꺼내기 |
| 두 번 누르기 / 오른쪽 클릭 | 바로 착용 (가방) · 해제 (장비) · 꺼내기 (보관함) |
| 끌어다 놓기 | 장비 칸에 놓으면 착용, 가방·보관함의 다른 칸에 놓으면 옮기기(물건이 있으면 맞바꿈), 반지 두 칸끼리 맞바꾸기, 상인 창에 놓으면 판매, 강화·재련 창에 놓으면 대상으로 고르기 |
| 터치: 길게 누른 채 끌기 | 위와 같음 (그냥 밀면 창이 스크롤됨) |

터치 화면에서도 동작합니다. 화면을 눌러 이동·공격하고, 아래 스킬 버튼을 누르면 가장 가까운 적을 자동으로 조준합니다.

## 핵심 시스템

### 마을: 국경 야영지
새 게임은 숲속 공터의 야영지에서 시작합니다. 가운데의 **심연의 문**(빛나는 돌 원)으로 던전에 들어갑니다.

| 주민 | 하는 일 |
| --- | --- |
| 대장장이 브론 | 장비 사고팔기, 판 물건 되사기, 물건 새로 들여오기, **강화 +1 ~ +10** (단계마다 기본 피해·방어력 +7%, +3부터 실패 가능 · 실패해도 장비는 그대로) |
| 약초상 마라 | 말을 걸면 생명력·중독 회복. 생명력 물약, 10분짜리 비약 3종(힘·무쇠·행운) |
| 떠돌이 상인 실렌 | 도박: 부위를 골라 사면 무엇이 나올지 모르는 물건 (대부분 마법, 가끔 레어·세트·유니크) |
| 재련사 쿠루 | 재련(마법·레어 아이템 능력치 다시 굴리기), 승급(일반 → 마법 → 레어) |
| 보관함 | 4쪽 × 48칸 (192칸). 죽거나 다시 시작해도 남습니다 |
| 심연의 문 · 오벨리스크 | 웨이포인트: 1층과 보스를 잡은 다음 층(6, 11, 16층 …)으로 바로 이동, 열린 차원문으로 돌아가기 |
| 경비대장 에드릭 | **퀘스트**와 현상금, **용병 고용·장비 맡기기·되살리기** |
| 주민들 | 몬스터 공략 팁과 이야기, **퀘스트**(머리 위 ! · ?) (상인들도 퀘스트 탭으로 부탁을 줌) |

- 아이템은 **마을 상인 창이 열려 있을 때만** 팔 수 있습니다. 던전에서는 버리기만 됩니다.
- 던전에서 **T**를 누르면 그 자리에 차원문이 열리고 마을로 갑니다. 마을의 차원문을 밟으면 떠났던 곳으로 돌아갑니다(층 상태 그대로).
- 죽으면 마을에서 깨어나고(골드 10% 잃음), 쓰러진 층의 입구로 가는 차원문이 열려 있습니다.
- 대장장이 물건은 마을에 올 때마다 바뀝니다.

### 퀘스트
마을 사람 머리 위에 **!**(새 퀘스트)나 **?**(보고할 퀘스트)가 뜨면 말을 걸어 보세요. 진행 중인 퀘스트는 화면 왼쪽 위와 캐릭터 창(C)에 표시됩니다.

퀘스트는 10가지 목표로 나뉩니다: **처치**, **보스 처치**, **물건 찾기**, **보석 가져가기**, **구출**(층 어딘가에 갇힌 사람을 찾아 누르기), **모으기**(몬스터가 떨어뜨리는 물건, 다가가면 자동으로 주움), **보물 상자 열기**, **층 도달**, **골드 내기**, **아이템 건네기**.

- 퀘스트 물건(반지, 망치)은 퀘스트를 받은 뒤에만 떨어지고, 팔거나 버릴 수 없습니다. 보고하면 사라집니다
- 모으는 물건(씨앗 자루, 운철 조각, 약초)은 퀘스트를 받은 뒤에만 떨어지고, 가방 칸을 차지하지 않습니다
- 골드 내기·아이템 건네기는 보고할 때 가방의 골드·아이템을 가져갑니다 (건네는 아이템은 조건에 맞는 것 중 가장 싼 것)
- **현상금**(되풀이): '계단을 지키는 자'를 마친 뒤 경비대장에게 받습니다. 특정 몬스터 N마리, 정예 N마리, 이름 있는 정예 N마리, 보물 상자 N개, 저주받은 무덤 N개, 보스 1마리 중 하나가 나오고, 골드·경험치·장비를 줍니다. 열 번째마다 기술 포인트도 1점
- 기술 보상은 기술 포인트로 받아 기술 창(K)에서 씁니다

### 레벨업 → 기술 포인트, 기술 창(K)에서 직접 고르기
레벨이 오를 때마다 **기술 포인트 1점**이 생깁니다(게임은 멈추지 않음). 화면 아래 **기술(K)** 버튼에 남은 포인트가 표시되고, 기술 창을 열어 **원하는 기술을 골라 배우거나 레벨을 올립니다**(최대 5, 아이템의 "모든 스킬 +N"으로 그 이상 가능). 포인트는 모아 두었다가 나중에 써도 됩니다.
- 기술 창은 공격 기술 / 방어·강화 / 패시브 / 능력치 탭으로 나뉩니다. 기술마다 지금 효과와 다음 레벨 효과가 보이고, 마우스를 올리면 자세한 설명이 나옵니다
- 몇몇 새 기술은 캐릭터 레벨이 되어야 배울 수 있습니다(레벨 3~24)
- **배울 수 있는 액티브 기술 수에 제한이 없습니다.** 단축칸은 6칸이고, 기술 창에서 배운 액티브 기술마다 있는 **1~6 버튼**으로 어느 칸에 둘지 고릅니다(원래 있던 기술과 자리를 맞바꾸고, 단축칸에 없던 기술이면 그 칸의 기술을 대신함)
- **능력치** 탭에서는 기술 대신 생명의 정수(최대 생명력, 레벨에 비례), 전사의 힘(모든 피해 +3% 영구), 불굴의 몸(방어력 +5% 영구), 전쟁 자금, 물약 꾸러미를 1점씩 올릴 수 있습니다
- 게임을 시작하면 포인트 1점과 함께 기술 창이 열려 첫 기술을 고릅니다. 퀘스트·현상금의 기술 보상도 포인트로 받습니다
- 예전 저장에서 고르지 않은 레벨업 카드·기술 카드는 불러올 때 포인트로 바뀝니다

**단축키 자리 바꾸기**: 기술 창이나 캐릭터 창(C)의 **1~6 버튼**, 또는 창이 열려 있을 때(게임이 멈춘 동안) 화면 아래 스킬 칸을 다른 칸으로 **끌어다 놓기**. 창이 닫혀 있을 때는 스킬 칸을 누르면 평소처럼 스킬을 씁니다. 바꾼 자리는 저장됩니다.

기술은 모두 42개(액티브 22 + 패시브 20, 각 최대 5레벨)입니다.

| 액티브 | 효과 |
| --- | --- |
| 강타 | 강한 단일 타격, 밀쳐내기 + 기절 |
| 소용돌이 | 키를 누르는 동안 회전하며 이동, 주변 지속 피해 |
| 도약 강타 | 커서 위치로 도약해 착지 범위 피해 + 기절 |
| 전투의 함성 | 주변 모든 적 피해 + 긴 기절 |
| 대지 분쇄 | 앞쪽으로 뻗어가는 균열 |
| 투척 도끼 | 관통하는 원거리 도끼 (레벨에 따라 개수 증가) |
| 광폭화 | 일정 시간 피해·공격 속도·이동 속도·흡혈 증가 |
| 광란 | 두 번 연달아 베기, 맞힐 때마다 공격·이동 속도가 쌓임 (최대 5번) |
| 처형 일격 | 무거운 일격, 생명력 30% 아래 적에게 2배 피해, 처치하면 분노 환급 |
| 지진 | 주변 땅을 세 번 흔들어 범위 피해 + 둔화 |
| 돌진 | 커서 쪽으로 돌진하며 길목의 적을 들이받음, 돌진 중 무적 (회피용) |
| 작살 | 사슬 창으로 적을 끌어와 기절 (보스는 기절만) |
| 강철 피부 | 몇 초 동안 받는 피해 크게 감소, 둔화 면역 |
| 전투 명령 | 30초 넘게 최대 생명력·방어력 증가 |
| 투지 회복 | 3초 동안 생명력 회복 + 중독·둔화 해제 |
| **회전 도끼** (레벨 3) | 커다란 도끼가 날아갔다가 **되돌아오며** 오가는 길의 적을 모두 벰 (벽에 닿으면 바로 돌아옴) |
| **사슬 올가미** (레벨 9) | 사방으로 사슬을 던져 **주변 적을 모두 끌어오고** 기절 (보스는 기절만). 소용돌이·지진과 함께 쓰기 좋음 |
| **공포의 포효** (레벨 12) | 주변 적이 **겁에 질려 달아나고**, 몇 초 동안 받는 피해 증가 (보스는 피해 증가만) |
| **전쟁 깃발** (레벨 15) | 발밑에 깃발을 꽂아, 범위 안에서 **모든 피해 증가 + 생명력 회복**(용병도 회복), 범위 안의 적은 느려짐 |
| **조상의 부름** (레벨 18) | **조상의 혼 2~3명을 불러** 함께 싸움 (푸른빛의 반투명한 야만용사, 공격받지 않음) |
| **선혈의 의식** (레벨 21) | 지금 생명력의 15%를 바치고, 몇 초 동안 때릴 때마다 **맞은 적 둘레의 적에게 피가 튐** |
| **천둥 강림** (레벨 24) | 커서 둘레에 **낙뢰를 여러 번** 떨어뜨려 맞은 적에게 피해 + 기절 |

패시브 20종: 무기 숙련, 단련된 피부, 강인함, 피의 갈증, 전투 질주, 분노의 심장, 처형인, 재생력, 가시 갑주, 보물 사냥꾼, **방패 숙련**(막기 확률·막을 때 분노), **자연 저항**(모든 저항), **강철 의지**(받는 피해 감소, 둔화·중독 시간 감소), **최후의 저항**(생명력 35% 아래에서 받는 피해 감소), **학살**(처치할 때마다 피해·공격 속도 중첩), **응징**(맞으면 확률로 반격), **무거운 일격**(양손 무기 피해, 기본 공격 기절), **생명의 샘**(물약 회복량, 처치 시 회복), **피의 분노**(레벨 6, 생명력 절반 아래에서 피해·생명력 흡수 증가), **불굴**(레벨 20, 쓰러질 만큼 맞으면 한 번 버티고 잠깐 무적, 45~105초마다).

자원은 **분노**입니다. 시간이 지나면 차오르고, 적을 때리거나 맞으면 더 빨리 찹니다.

### 아이템
- 장비 칸 10개: 무기, **방패**, 투구, 목걸이, 갑옷, 반지 2, 장갑, 허리띠, 장화
- 희귀도: **일반**(흰색) · **마법**(파랑, 속성 1–2개) · **레어**(노랑, 속성 3–6개, 무작위 이름) · **세트**(초록, 6세트 27종) · **유니크**(황금색, 62종: 장비 54 + 부적 8)
- 기본형 107종: 무기 34종, 방패 12종, 방어구 61종. 레벨 40~100의 **상위 기본형**(룬 새김 도끼, 거인 학살자, 폭풍 망치, 그림자 송곳니, 용의 이빨, 심연의 도끼, 신살의 대검, 성채 방패, 군주의 왕관, 심연의 갑주, 신의 갑옷 …)이 있어 50층 뒤와 악몽·지옥에서도 더 좋은 장비가 나옵니다. 아이템 레벨에 가까운 기본형일수록 자주 나옵니다
- **양손 무기**(대형 망치, 쌍날 도끼, 대검, 츠바이헨더 …)는 피해가 크고 사거리가 길지만 방패를 들 수 없습니다. 방패는 근접 공격과 투사체를 **막기**(피해 0)할 확률을 줍니다
- 접두사/접미사 39종 (+부적 전용 8종): 화염·냉기·번개 추가 피해, 언데드 추가 피해, **정예·보스 추가 피해**, **받는 피해 -%**, **둔화·중독 시간 감소**, **기본 공격 기절 확률**, **적중 시 연쇄 번개·화염 폭발·서리 폭발**, 처치 시 생명력·분노, 재사용 대기시간 감소, 원소 저항, **특정 스킬 레벨 +1~2** 등. 주요 속성은 레벨 40~95에 더 높은 단계가 있습니다
- 세트: 부족장의 유산(4), 서리 늑대의 맹세(4), 고대 왕의 갑주(5), **광전사 군주의 분노**(4, 40레벨대), **성기사의 맹세**(5, 60레벨대), **심연 정복자**(5, 80레벨대)
- 강화된 장비는 이름 앞에 +N이 붙습니다
- 착용한 투구·갑옷·장갑·장화·무기·방패가 캐릭터 그림에 그대로 보입니다
- 요구 레벨이 있어 너무 좋은 장비는 레벨을 올려야 착용할 수 있습니다

### 보석과 소켓
- 무기·갑옷(최대 3), 투구·방패(최대 2)에 **소켓**이 생길 수 있습니다 (일반 아이템일수록 잘 생김). 대장장이의 **소켓 · 보석** 탭에서 골드를 내고 소켓을 뚫을 수도 있습니다 (유니크·세트도 가능)
- **보석**은 몬스터가 떨어뜨립니다 (한 층에 3–4개, 정예·보스일수록 잘 나옴). 소지품 창에서 보석을 소켓 있는 장비 위로 **끌어다 놓으면** 박힙니다. 박은 보석은 빼낼 수 없습니다
- 등급 5단계(깨진 → 흠 있는 → 보통 → 완벽한 → 왕실의). 같은 보석 3개를 대장장이가 한 등급 위로 **합성**해 줍니다

| 보석 | 무기에 박으면 | 갑옷·투구·방패에 박으면 |
|---|---|---|
| 루비 | 화염 피해 +4 → +40 | 생명력 +10 → +80 |
| 사파이어 | 냉기 피해 +3 → +34 | 최대 분노 +5 → +28 |
| 에메랄드 | 치명타 피해 +8% → +60% | 초당 생명력 회복 +1 → +11 |
| 다이아몬드 | 언데드 추가 피해 +20% → +130% | 모든 원소 저항 +4% → +22% |

### 부적
- 소지품 창의 **부적 주머니(8칸)**에 넣은 부적만 효과가 있습니다. 가방 칸을 차지하지 않고, 한 번에 최대 8개까지라 가방이 부적으로 가득 찰 일이 없습니다
- 가방의 부적을 **두 번 누르면** 주머니에 들어가고, 주머니의 부적을 두 번 누르면 가방으로 나옵니다. 주머니가 가득 차면 바꿀 부적을 끌어다 놓아 맞바꿉니다 (착용 레벨이 되어야 효과)
- 작은 부적 → 큰 부적(20) → 거대한 부적(45) → 고대의 부적(75)
- **부적은 레어(노란색)와 유니크(금색)로만 떨어집니다.** 레어 부적은 생명력, 피해, 추가 피해, 마법 아이템 발견, 원소 저항, 치명타, 방어력, 골드 중 2–3개. 유니크 부적은 보스·정예에게서, 그리고 마법 아이템 발견이 높을수록 더 자주 나옵니다
- 한 층에 1–2개 떨어지고, 떠돌이 상인에게 도박으로 살 수도 있습니다(늘 레어 이상, 값은 다른 물건보다 비쌈)

| 유니크 부적 | 종류(레벨) | 효과 |
|---|---|---|
| 떠돌이의 행운 | 작은 부적(3) | 마법 아이템 발견, 골드 획득, 생명력 |
| 전사의 징표 | 작은 부적(8) | 모든 피해 %, 피해 +, 생명력 |
| 수호자의 토템 | 큰 부적(18) | 모든 원소 저항, 방어력, 생명력 |
| 피의 계약 | 큰 부적(25) | 생명력 흡수, 모든 피해 %, 치명타 피해 |
| 폭풍 독수리의 깃털 | 큰 부적(32) | 이동 속도, 공격 속도, 피해 + |
| 고대 부족의 횃불 | 거대한 부적(45) | **모든 스킬 +1**, 생명력, 모든 원소 저항 |
| 망자의 눈물 | 거대한 부적(55) | 경험치, 마법 아이템 발견, 처치 시 생명력, 생명력 |
| 오르쿠스의 파편 | 고대의 부적(75) | **모든 스킬 +1**, 모든 피해 %, 생명력, 원소 저항, 경험치 |

### 용병
마을의 **경비대장 에드릭**에게 말을 걸면 '용병' 탭에서 고용합니다. 용병은 주인을 따라다니며 함께 싸우고, 주인이 얻는 경험치만큼 레벨이 올라갑니다(주인 레벨까지). 고용 비용은 주인 레벨에 따라 오릅니다.

| 용병 | 특징 | 기술 |
|---|---|---|
| 검사 | 방패를 든 근접 전사. 생명력·방어력이 높음 | **방패 강타**: 6초마다 다음 공격이 피해 150%, 1.2초 기절 |
| 투척수 | 멀리서 단검을 던짐. 몸이 약함 | **부채 던지기**: 5초마다 단검 3자루를 부채꼴로 |
| 전투 사제 | 철퇴를 든 사제 | **회복의 기운**: 곁에 있는 주인과 사제의 생명력이 계속 회복 / **치유 기도**: 14초마다 위급할 때 둘 다 생명력 25% 회복 |

- **장비 맡기기**: 소지품 창(I)에 **용병 장비 칸**(무기·갑옷·투구, 검사·전투 사제는 방패도)이 있습니다. 던전에서도 가방이나 내 장비 칸의 물건을 끌어다 놓거나, 아이템을 누르고 **'용병에게'** 버튼을 누르면 맡겨집니다. 용병 칸을 두 번 누르거나 오른쪽 클릭하면 가방으로 돌아오고, 내 장비 칸이나 가방으로 끌어 옮길 수도 있습니다. 경비대장 창의 용병 탭에서도 맡길 수 있습니다(소지품 창이 함께 열려 탭 위로 끌어다 놓아도 됨)
- 착용 레벨은 용병 레벨 기준이고, 맡긴 장비의 능력치(생명력, 피해 %, 생명력 흡수, 저항 …)와 소켓 보석도 적용됩니다. 양손 무기를 맡기면 방패는 가방으로 돌아옵니다. 겉모습도 맡긴 갑옷·투구·무기로 바뀝니다
- 용병은 주인보다 조금 작고, 갑옷과 투구에 종류마다 색이 입혀져 있습니다(검사 푸른 강철, 투척수 숲빛 초록, 전투 사제 흰 금빛). 머리 위에 이름과 생명력 막대가 있습니다
- 몬스터는 주인과 용병 중 가까운 쪽을 노립니다. 용병은 이미 싸움에 끼어든 적과 가까이 있는 적만 상대하고, 주인에게서 너무 멀어지면 돌아옵니다(먼 무리를 끌고 오지 않게)
- 싸우지 않을 때는 생명력이 빠르게 차고, 주인이 물약을 마시면 용병도 생명력 40%를 회복합니다
- 쓰러지면 경비대장에게 골드를 내고 되살립니다(최대 50,000 골드). 내보내면 맡긴 장비는 돌려받습니다
- 화면 왼쪽 위에 용병의 이름·레벨·생명력 막대가 보이고, 발밑에 초록 고리가 있습니다

### 던전 (50층, 엔딩 있음)
- 매 층 무작위 생성, 탐험한 곳만 보이는 시야와 미니맵
- **테마 19가지 × 맵 구조 9가지를 섞음**: 층마다 테마(지하 11, 바깥 8)와 그 테마에 맞는 맵 구조가 나옵니다. 어떤 층에 어떤 테마가 나올지는 **캐릭터마다 다르고**(악몽·지옥도 따로), 한 캐릭터 안에서는 같은 층이 늘 같은 테마라 웨이포인트에 이름이 붙습니다. 맵 모양은 들어갈 때마다 새로 만듭니다
- 바깥 지역 비율: 20층 전에는 열에 셋, 20층부터는 열에 여섯 정도. 1층은 늘 '어둠의 묘지', 50층은 '망자의 왕좌'
- 지하 맵 구조
  - **방과 통로**: 네모난 방들을 통로로 이음
  - **자연 동굴**: 울퉁불퉁한 굴을 구불구불한 굴길로 잇고, 굴 안에 종유석 기둥
  - **대전당**: 기둥이 두 줄로 늘어선 큰 홀과 곁방들, 바닥에 세운 화로
  - **미궁**: 좁은 길이 얽힌 미로, 군데군데 넓은 방과 막다른 길 끝의 작은 방
  - **원형 성소**: 둥글게 늘어선 방을 고리 통로가 잇고, 반대편 길로만 들어가는 가운데 성소에 계단

- 지하 테마: 어둠의 묘지, 망자의 동굴, **버려진 광산**(버팀목·사다리 벽), 버려진 성채, **왕가의 납골당**(석관·석상), **이끼 낀 고대 유적**(Flare 유적 타일), **잊힌 서고**(책장 벽·독서대), 불타는 심연, **버섯 동굴**(빛나는 버섯), 혼돈의 성역, 얼어붙은 지하묘지

정예 속성 9종: 빠름, 강함, 돌가죽, 화염 강화(죽을 때 폭발), 냉기 강화(둔화), 흡혈, 번개 강화(맞으면 전기 구슬), 순간이동, 독 강화(중독, 죽으면 독 웅덩이).

중독과 얼음, 화염·마력 공격은 **원소 저항**으로 줄일 수 있습니다.

## 그래픽

캐릭터, 몬스터, 던전 타일, 아이콘은 **Flare: Empyrean Campaign** 프로젝트의 무료 스프라이트입니다. 디아블로풍 3D 프리렌더 그림으로, 8방향 애니메이션이 있습니다.

- **야만용사**: 웃통을 벗은 기본 몸 위에 머리·몸통·다리·손·발·무기 레이어를 겹쳐 그립니다. 가죽/사슬/판금 장비를 착용하면 그 모습으로 바뀝니다. 무기 종류(손도끼, 쌍날 도끼, 장검, 대검, 철퇴, 전쟁 망치)도 그대로 보입니다.
- **몬스터**: 위 표의 모든 몬스터가 Flare 그림입니다 (사람형 적은 주인공 장비 레이어를 겹쳐 그림, 바위 투척 미노타우로스의 바위는 Flare `boulder` 그림)(폭풍 비룡, 광차 고블린, 거대한 폭풍의 비룡왕 포함). 대기·달리기·공격·죽음 동작이 있고, 매복하는 몬스터는 땅에서 솟아오르는 동작도 있습니다.
- **마을**: Flare 풀밭 타일셋의 풀밭·돌길·나무·천막·모루·모닥불·상자·묘비와 빛나는 돌 원, NPC 그림(대장장이, 약초상, 상인, 고블린 행상, 기사, 주민, 오벨리스크)
- **방패**: 버클러, 둥근 방패, 철 버클러, 카이트 방패 레이어가 캐릭터 그림에 보입니다
- **던전**: 석재 던전, 동굴, 이끼 낀 유적(empyrean_campaign) 타일셋. 테마마다 색을 입혀 성채(초록), 불타는 심연(붉은색), 혼돈의 성역(보라), 버섯 동굴(연보라)을 만듭니다. 방 앞쪽 벽은 디아블로처럼 낮게 잘라 그려서 방 안이 가려지지 않습니다. 홀로 선 벽은 기둥(던전 기둥, 종유석, 광산 버팀목, 유적 기둥)으로 그립니다.
- **바깥**: 풀밭 타일셋에 테마마다 색을 입히고(필터), 설원 테마는 Flare 설원 타일셋(눈밭, 마른 나무, 눈 덮인 바위)을 씁니다.
- **소품**: 벽걸이 횃불, 화로, 가시 달린 보물 상자, 계단 구덩이, 뼈 무더기, 석상, 석관, 제단, 탁자, 독서대, 통, 상자, 쇠사슬, 광차, 버섯, 종유석, 유적 석상·항아리·우물·성소·식물
- **아이콘**: 아이템과 스킬 아이콘
- **스킬 효과**: 휘두를 때 칼날 궤적, 도약 착지 지진, 대지 분쇄의 솟아오르는 가시, 함성·광폭화의 주황 고리, 회전하며 날아가는 도끼, 화살, 화염구와 폭발, 얼음창, 독침, 마력구, 연쇄 번개의 낙뢰, 소환 마법진, 순간이동 어둠 안개, 차원문 룬, 타격 불꽃, 물약·레벨업 빛
- 조명, 피 튀김, 화면 흔들림, 피해 숫자는 코드로 그립니다.

### 그래픽 품질 (메뉴 → 그래픽)
기본값은 **자동**입니다. 실제 프레임 간격을 2초마다 재서, 렉이 생기면(약 50fps 아래로 떨어지면) 한 단계 낮추고 12초 넘게 여유가 있으면 한 단계 올립니다. 한 번 버거웠던 단계는 1분 반 동안 다시 올리지 않아 품질이 오르락내리락하지 않습니다. 휴대 기기는 '보통', 컴퓨터는 '높음'에서 시작합니다. 직접 높음 / 보통 / 낮음으로 고정할 수도 있습니다.

| | 낮음 | 보통 | 높음 |
|---|---|---|---|
| 화면 해상도 상한 (고해상도 화면) | 1배 | 1.25배 | 1.5배 |
| 그림자 | 발밑 그림자 | 빛 반대쪽으로 늘어지는 그림자 | 캐릭터 모양 실루엣 그림자 |
| 떠다니는 입자 | 없음 | 50개 | 110개 |
| 화면 가장자리 어둡게 · 구름 그림자(바깥) | | ✓ | ✓ |
| 빛 번짐 · 안개 | | | ✓ |

- **그림자**: 지하에서는 주인공이 든 빛의 반대쪽으로, 바깥에서는 하늘빛 방향으로 늘어집니다. 실루엣 그림자는 그림을 반 크기 검은 실루엣으로 한 번 만들어 두고 바닥에 눕혀 그려서, 가장자리가 부드럽고 가볍습니다
- **테마별 입자**: 먼지(묘지·동굴·성채), 불씨(불타는 심연·불타는 평원), 서리(얼어붙은 지하묘지), 포자(역병의 늪지), 핏빛 재(핏빛 황야), 재(잿빛 황무지), 푸른 도깨비불(그림자 숲), 눈(얼어붙은 설원), 금빛 불티(망자의 왕좌), 반딧불이(마을)
- **안개**: 동굴, 얼어붙은 지하묘지, 늪지, 그림자 숲, 설원, 마을, 왕좌에 흐르는 안개 두 겹. 조명보다 먼저 그려서 빛을 받은 곳의 안개만 보입니다
- **가볍게 만든 부분**: 조명은 색마다 미리 그려 둔 빛 그림을 늘려 쓰고(매 프레임 그라디언트를 만들지 않음), 바닥 핏자국·균열은 미리 그린 그림을 쓰며 화면 밖은 건너뜁니다. 안개와 빛 번짐은 작은 버퍼에서 처리해 화면에는 한 번만 그리고, 가장자리 어둡게는 조명 지도에 함께 곱해 추가 비용이 거의 없습니다. 색을 입힌 몬스터 그림과 그림자 실루엣은 층에 들어갈 때 미리 만들어, 몬스터가 처음 나올 때 멈칫하지 않습니다

### 효과음

Flare 효과음 86개를 씁니다: 휘두르기, 함성, 지진, 가시, 화염, 번개, 물약, 레벨업, 금화, 장비 종류별 착용 소리, 방패 막기, 상자, 계단, 발소리, 체력이 낮을 때 심장 박동, 몬스터마다 다른 공격·피격·죽음·발견 울음, 무덤 소리, 순간이동·차원문, 상인 목소리, 배경음(던전 물방울, 동굴 바람, 마을 새소리). 효과음 파일을 아직 불러오지 못했으면 즉석 합성한 소리로 대신합니다.

그림을 아직 불러오지 못했거나 불러오기에 실패하면, 이전 버전의 코드로 그린 그림으로 대신 표시합니다.

### 그림 자원 다시 만들기

`assets/flare/`의 그림은 Flare 원본에서 필요한 프레임만 골라 70% 크기의 WebP 아틀라스로 다시 묶은 것이고, 효과음은 MP3로 바꿔 `sounds.js`에 담았습니다(합계 약 33MB). 처음에는 타일, 기본 몸, 마을 사람, 1층 몬스터, 효과 그림만 불러오고 나머지는 그 층에 들어갈 때 불러옵니다. 효과음 변환에는 `ffmpeg`가 필요합니다. 일부 몬스터·NPC(홉고블린, 어둠의 망자, 해골 기사·대마법사·왕, 갑각 개미귀신, 고블린 행상)와 유적 타일셋은 같은 저장소의 `mods/empyrean_campaign`에서 가져옵니다. 처음에는 던전·동굴·풀밭 타일셋만 불러오고, 설원·유적 타일셋은 그 테마의 층에 들어갈 때 불러옵니다.

```
git clone --depth 1 https://github.com/flareteam/flare-game.git
python3 -I tools/build_flare_assets.py flare-game/mods/fantasycore assets/flare
# 타일셋만 다시 만들기 (캐릭터·몬스터·소리는 그대로)
python3 -I tools/build_flare_assets.py flare-game/mods/fantasycore assets/flare --tiles dungeon cave ruins snow
```

몬스터나 장비 레이어를 더 넣으려면 `tools/build_flare_assets.py` 위쪽의 목록에 이름을 추가하고 다시 실행하면 됩니다.
