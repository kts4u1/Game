# 핏빛 심연 — 야만용사 핵앤슬래시

디아블로 2 스타일의 아이소메트릭(비스듬한 시점) 액션 RPG 프로토타입입니다.
야만용사로 끝없이 이어지는 지하 묘지를 내려가며 몬스터를 사냥하고, 레벨업마다 기술 카드 3장 중 하나를 고르고, 떨어진 장비를 주워 착용합니다.

설치나 빌드 없이 브라우저만으로 실행됩니다. 캐릭터·몬스터·던전 그림은 무료 공개 그림 자원인 [Flare 프로젝트](https://github.com/flareteam/flare-game)의 스프라이트(CC-BY-SA 3.0)를 쓰고, 효과음은 WebAudio로 즉석 합성합니다.

## 실행 방법

- `index.html`을 브라우저(크롬, 엣지, 파이어폭스, 사파리)로 열면 바로 실행됩니다.
- 또는 로컬 서버로: `python3 -m http.server 8000` 실행 후 `http://localhost:8000` 접속

진행 상황은 브라우저 저장소에 자동 저장됩니다(층 이동, 레벨업 시). 타이틀 화면의 **이어하기**로 계속할 수 있습니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 왼쪽 클릭 | 이동 · 공격 · 아이템 줍기 · 상자 열기 · 계단 (누르고 있으면 계속) |
| WASD / 방향키 | 키보드로 이동 |
| 1 – 4 | 스킬 사용 (커서 방향으로) |
| 오른쪽 클릭 | 1번 스킬 |
| Shift + 클릭 | 제자리 공격 |
| Q | 생명력 물약 |
| I / C | 소지품 / 캐릭터 정보 |
| Tab | 전체 지도 |
| M | 소리 켜기/끄기 |
| Esc | 메뉴 (일시정지) |

터치 화면에서도 동작합니다. 화면을 눌러 이동·공격하고, 아래 스킬 버튼을 누르면 가장 가까운 적을 자동으로 조준합니다.

## 핵심 시스템

### 레벨업 → 기술 카드 3장 중 선택
레벨이 오르면 게임이 멈추고 카드 3장이 나옵니다. 하나를 고르면 새 기술을 배우거나 이미 배운 기술의 레벨이 오릅니다(최대 5, 아이템의 "모든 스킬 +N"으로 그 이상 가능).
게임 시작 시에도 첫 액티브 기술을 3장 중에서 고릅니다. 액티브 기술은 최대 4개까지 단축키(1–4)에 들어갑니다.

| 액티브 | 효과 |
| --- | --- |
| 강타 | 강한 단일 타격, 밀쳐내기 + 기절 |
| 소용돌이 | 키를 누르는 동안 회전하며 이동, 주변 지속 피해 |
| 도약 강타 | 커서 위치로 도약해 착지 범위 피해 + 기절 |
| 전투의 함성 | 주변 모든 적 피해 + 긴 기절 |
| 대지 분쇄 | 앞쪽으로 뻗어가는 균열 |
| 투척 도끼 | 관통하는 원거리 도끼 (레벨에 따라 개수 증가) |
| 광폭화 | 일정 시간 피해·공격 속도·이동 속도·흡혈 증가 |

패시브 10종: 무기 숙련, 단련된 피부, 강인함, 피의 갈증, 전투 질주, 분노의 심장, 처형인, 재생력, 가시 갑주, 보물 사냥꾼.

자원은 **분노**입니다. 시간이 지나면 차오르고, 적을 때리거나 맞으면 더 빨리 찹니다.

### 아이템
- 장비 칸 9개: 무기, 투구, 목걸이, 갑옷, 반지 2, 장갑, 허리띠, 장화
- 희귀도: **일반**(흰색) · **마법**(파랑, 속성 1–2개) · **레어**(노랑, 속성 3–5개, 무작위 이름) · **유니크**(황금색, 고정 이름과 특수 능력 18종)
- 기본형 40종이 아이템 레벨에 따라 등장 (손도끼 → 전투 도끼 → 광전사 도끼 → 고대 도끼 등)
- 접두사/접미사 19종, 아이템 레벨이 높을수록 더 높은 등급의 수치가 붙습니다
- 착용한 투구·갑옷·장갑·장화·무기가 캐릭터 그림에 그대로 보입니다
- 요구 레벨이 있어 너무 좋은 장비는 레벨을 올려야 착용할 수 있습니다

### 몬스터 레벨이 오를수록 좋은 아이템
층이 깊어질수록 몬스터 레벨이 오르고, 아이템 희귀도 확률이 올라갑니다. 일반 몬스터가 아이템을 떨어뜨렸을 때의 희귀도 분포(마법 아이템 발견 0% 기준):

| 몬스터 레벨 | 일반 | 마법 | 레어 | 유니크 |
| --- | --- | --- | --- | --- |
| 1 | 79% | 21% | 0% | 0% |
| 3 | 71% | 24% | 4.2% | 0.8% |
| 6 | 65% | 27.5% | 6.4% | 1.2% |
| 10 | 58% | 31.6% | 8.8% | 1.8% |
| 15 | 47% | 37.7% | 12.8% | 2.6% |
| 20 | 37% | 44% | 15.5% | 3.3% |

챔피언(파란 기운)은 유니크 확률 3배, 정예(황금 기운, 이름 있음)는 5배, 보스는 10배이며 보스는 레어 이상을 반드시 1개 이상 떨어뜨립니다. 보물 상자도 좋은 아이템이 나옵니다.
유니크·레어가 떨어지면 빛기둥과 효과음으로 알려줍니다.

### 던전
- 매 층 무작위 생성 (방 + 통로), 탐험한 곳만 보이는 시야와 미니맵
- 5가지 테마: 어둠의 묘지 → 망자의 동굴 → 버려진 성채 → 불타는 심연 → 혼돈의 성역
- 몬스터 7종: 좀비, 해골 창병, 해골 석궁병, 고블린(무리), 해골 마법사(화염구), 개미귀신(흡혈), 미노타우로스
- 보스 4종: 도살자 모르그(미노타우로스), 해골 군주 바르곤, 역병의 어미, 심연의 비룡 아즈라크
- 정예 속성: 빠름, 강함, 돌가죽, 화염 강화(죽을 때 폭발), 냉기 강화(둔화), 흡혈
- 5층마다 보스가 계단을 지키며, 보스를 쓰러뜨려야 다음 층으로 내려갈 수 있습니다

## 그래픽

캐릭터, 몬스터, 던전 타일, 아이콘은 **Flare: Empyrean Campaign** 프로젝트의 무료 스프라이트입니다. 디아블로풍 3D 프리렌더 그림으로, 8방향 애니메이션이 있습니다.

- **야만용사**: 웃통을 벗은 기본 몸 위에 머리·몸통·다리·손·발·무기 레이어를 겹쳐 그립니다. 가죽/사슬/판금 장비를 착용하면 그 모습으로 바뀝니다. 무기 종류(손도끼, 쌍날 도끼, 장검, 대검, 철퇴, 전쟁 망치)도 그대로 보입니다.
- **몬스터**: 좀비, 해골 창병, 해골 석궁병, 해골 마법사, 고블린, 개미귀신, 미노타우로스, 화염 비룡(보스). 대기·달리기·공격·죽음 동작이 있습니다.
- **던전**: 석재 던전과 동굴 타일셋. 테마마다 색을 입혀 성채(초록), 불타는 심연(붉은색), 혼돈의 성역(보라)을 만듭니다. 방 앞쪽 벽은 디아블로처럼 낮게 잘라 그려서 방 안이 가려지지 않습니다.
- **소품**: 벽걸이 횃불, 화로, 가시 달린 보물 상자, 계단 구덩이, 뼈 무더기
- **아이콘**: 아이템과 스킬 아이콘
- **스킬 효과**: 휘두를 때 칼날 궤적, 도약 착지 지진, 대지 분쇄의 솟아오르는 가시, 함성·광폭화의 주황 고리, 회전하며 날아가는 도끼, 해골 석궁병의 화살, 해골 마법사의 화염구와 폭발, 연쇄 번개의 낙뢰, 타격 불꽃, 물약·레벨업 빛
- 조명, 피 튀김, 화면 흔들림, 피해 숫자는 코드로 그립니다.

### 효과음

Flare 효과음 64개를 씁니다: 휘두르기, 함성, 지진, 가시, 화염, 번개, 물약, 레벨업, 금화, 장비 종류별 착용 소리, 상자, 계단, 발소리, 체력이 낮을 때 심장 박동, 몬스터마다 다른 공격·피격·죽음·발견 울음, 층 테마별 배경음(던전 물방울, 동굴 바람). 효과음 파일을 아직 불러오지 못했으면 즉석 합성한 소리로 대신합니다.

그림을 아직 불러오지 못했거나 불러오기에 실패하면, 이전 버전의 코드로 그린 그림으로 대신 표시합니다.

### 그림 자원 다시 만들기

`assets/flare/`의 그림은 Flare 원본에서 필요한 프레임만 골라 70% 크기의 WebP 아틀라스로 다시 묶은 것이고, 효과음은 MP3로 바꿔 `sounds.js`에 담았습니다(합계 약 16MB). 처음에는 바닥 타일, 기본 몸, 1층 몬스터, 효과 그림만 불러오고 나머지는 필요할 때 불러옵니다. 효과음 변환에는 `ffmpeg`가 필요합니다.

```
git clone --depth 1 https://github.com/flareteam/flare-game.git
python3 -I tools/build_flare_assets.py flare-game/mods/fantasycore assets/flare
```

몬스터나 장비 레이어를 더 넣으려면 `tools/build_flare_assets.py` 위쪽의 목록에 이름을 추가하고 다시 실행하면 됩니다.

### 라이선스

Flare 그림은 **CC-BY-SA 3.0**입니다. 이 게임을 배포하거나 공개할 때는 저작자 표시를 유지해야 하고, 그림을 고쳐서 배포하면 그 그림도 같은 라이선스로 공개해야 합니다. 자세한 저작자 목록은 `assets/flare/CREDITS.md`에 있습니다. 이 조건은 그림에만 적용되고 게임 코드에는 적용되지 않습니다.

## 파일 구조

```
index.html        화면 구성 (HUD, 패널, 오버레이)
assets/flare/     Flare 스프라이트 아틀라스(WebP), manifest.js(프레임 좌표), 저작자 표시
tools/build_flare_assets.py  Flare 원본 → 게임용 아틀라스 변환
css/style.css     UI 스타일
js/util.js        공통 함수, 아이소메트릭 좌표 변환
js/data.js        스킬, 아이템 기본형, 접두사/접미사, 유니크, 몬스터, 테마 데이터
js/items.js       아이템 생성, 희귀도 굴림, 툴팁
js/dungeon.js     던전 생성, 충돌, A* 길찾기, 시야
js/assets.js      Flare 그림 불러오기, 8방향 애니메이션, 장비 레이어, 아이콘
js/sprites.js     코드로 그린 캐릭터 (그림을 못 불러왔을 때 대신 사용)
js/icons.js       코드로 그린 아이콘 (위와 같음)
js/effects.js     파티클, 피해 숫자, 바닥 흔적
js/entities.js    몬스터 AI, 전투, 전리품, 투사체
js/player.js      능력치 계산, 이동, 스킬, 소지품, 레벨업 카드
js/render.js      타일·벽 깊이 정렬, 조명, 오버레이
js/ui.js          HUD, 소지품/캐릭터 창, 카드 선택
js/audio.js       효과음 합성
js/game.js        게임 루프, 입력, 층 이동, 저장
```

데이터 수정은 대부분 `js/data.js`에서 할 수 있습니다. 예를 들어 새 유니크를 추가하려면 `UNIQUES` 배열에 한 줄을 넣으면 됩니다.
