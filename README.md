# 망자의 왕관 (Crown of the Dead) — 야만용사 핵앤슬래시

디아블로 2 스타일의 아이소메트릭(비스듬한 시점) 액션 RPG 프로토타입입니다.
야만용사로 국경 야영지 마을에서 장비를 갖추고, 끝없이 이어지는 지하 묘지를 내려가며 몬스터를 사냥합니다. 레벨업마다 기술 카드 3장 중 하나를 고르고, 떨어진 장비를 주워 착용하고, 모은 골드는 마을 상인에게 씁니다.

설치나 빌드 없이 브라우저만으로 실행됩니다. 캐릭터·몬스터·던전·마을 그림과 효과음은 무료 공개 자원인 [Flare 프로젝트](https://github.com/flareteam/flare-game)의 것(CC-BY-SA 3.0)을 씁니다.

## 실행 방법

- `index.html`을 브라우저(크롬, 엣지, 파이어폭스, 사파리)로 열면 바로 실행됩니다.
- 또는 로컬 서버로: `python3 -m http.server 8000` 실행 후 `http://localhost:8000` 접속

진행 상황은 브라우저 저장소에 자동 저장됩니다(층 이동, 마을 이동, 레벨업 시). 타이틀 화면의 **이어하기**로 계속할 수 있습니다. 보관함에 넣은 물건과 열린 웨이포인트도 저장됩니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 왼쪽 클릭 | 이동 · 공격 · 아이템 줍기 · 상자 열기 · 계단 · 마을 사람과 대화 (누르고 있으면 계속) |
| WASD / 방향키 | 키보드로 이동 |
| 1 – 4 | 스킬 사용 (커서 방향으로) |
| 오른쪽 클릭 | 1번 스킬 |
| Shift + 클릭 | 제자리 공격 |
| Q | 생명력 물약 |
| T | 귀환 차원문 (던전 → 마을, 1.2초 시전) |
| L | 바닥 아이템 표시: 모든 아이템 → 마법 이상 → 레어 이상 |
| I / C | 소지품 / 캐릭터 정보 |
| Tab | 전체 지도 |
| M | 소리 켜기/끄기 |
| Esc | 메뉴 (일시정지) |

### 소지품 다루기

| 입력 | 동작 |
| --- | --- |
| 아이템 누르기 | 자세한 정보와 버튼(착용 · 판매/버리기 · 옮기기) 보기 |
| Shift + 클릭 | 상인 창이 열려 있으면 바로 판매 (대장장이에게서 되살 수 있음), 보관함이 열려 있으면 넣기·꺼내기 |
| 두 번 누르기 / 오른쪽 클릭 | 바로 착용 (가방) · 해제 (장비) · 꺼내기 (보관함) |
| 끌어다 놓기 | 장비 칸에 놓으면 착용, 가방·보관함의 다른 칸에 놓으면 옮기기(물건이 있으면 맞바꿈), 반지 두 칸끼리 맞바꾸기, 상인 창에 놓으면 판매, 강화·재련 창에 놓으면 대상으로 고르기 |
| 터치: 길게 누른 채 끌기 | 위와 같음 (그냥 밀면 창이 스크롤됨) |
| 옮기기 버튼 → 칸 누르기 | 끌기 없이 원하는 칸으로 옮기기 |
| 정리 버튼 | 가방(보관함)을 부위 → 희귀도 → 아이템 레벨 순으로 정렬 |

터치 화면에서도 동작합니다. 화면을 눌러 이동·공격하고, 아래 스킬 버튼을 누르면 가장 가까운 적을 자동으로 조준합니다.

## 핵심 시스템

### 마을: 국경 야영지
새 게임은 숲속 공터의 야영지에서 시작합니다. 가운데의 **심연의 문**(빛나는 돌 원)으로 던전에 들어갑니다.

| 주민 | 하는 일 |
| --- | --- |
| 대장장이 브론 | 장비 사고팔기, 판 물건 되사기, 물건 새로 들여오기, **강화 +1 ~ +10** (단계마다 기본 피해·방어력 +7%, +3부터 실패 가능 · 실패해도 장비는 그대로) |
| 약초상 마라 | 말을 걸면 생명력·중독 회복. 생명력 물약, 10분짜리 비약 3종(힘·무쇠·행운) |
| 떠돌이 상인 실렌 | 도박: 부위를 골라 사면 무엇이 나올지 모르는 물건 (대부분 마법, 가끔 레어·세트·유니크) |
| 재련사 쿠루 | 재련(마법·레어 아이템 능력치 다시 굴리기), 승급(일반 → 마법 → 레어) |
| 보관함 | 48칸. 죽거나 다시 시작해도 남습니다 |
| 심연의 문 · 오벨리스크 | 웨이포인트: 1층과 보스를 잡은 다음 층(6, 11, 16층 …)으로 바로 이동, 열린 차원문으로 돌아가기 |
| 경비대장 에드릭, 주민들 | 몬스터 공략 팁과 이야기 |

- 아이템은 **마을 상인 창이 열려 있을 때만** 팔 수 있습니다. 던전에서는 버리기만 됩니다.
- 던전에서 **T**를 누르면 그 자리에 차원문이 열리고 마을로 갑니다. 마을의 차원문을 밟으면 떠났던 곳으로 돌아갑니다(층 상태 그대로).
- 죽으면 마을에서 깨어나고(골드 10% 잃음), 쓰러진 층의 입구로 가는 차원문이 열려 있습니다.
- 대장장이 물건은 마을에 올 때마다 바뀝니다.

### 레벨업 → 기술 카드 3장 중 선택
레벨이 오르면 게임이 멈추고 카드 3장이 나옵니다. 하나를 고르면 새 기술을 배우거나 이미 배운 기술의 레벨이 오릅니다(최대 5, 아이템의 "모든 스킬 +N"으로 그 이상 가능).
게임 시작 시에도 첫 액티브 기술을 3장 중에서 고릅니다. 액티브 기술은 최대 4개까지 단축키(1–4)에 들어갑니다.

| 액티브 | 효과 |
| --- | --- |
| 강타 | 강한 단일 타격, 밀쳐내기 + 기절 |
| 소용돌이 | 키를 누르는 동안 회전하며 이동, 주변 지속 피해 |
| 도약 강타 | 커서 위치로 도약해 착지 범위 피해 + 기절 |
| 전투의 함성 | 주변 모든 적 피해 + 긴 기절 |
| 대지 분쇄 | 앞쪽으로 뻗어가는 균열 |
| 투척 도끼 | 관통하는 원거리 도끼 (레벨에 따라 개수 증가) |
| 광폭화 | 일정 시간 피해·공격 속도·이동 속도·흡혈 증가 |

패시브 10종: 무기 숙련, 단련된 피부, 강인함, 피의 갈증, 전투 질주, 분노의 심장, 처형인, 재생력, 가시 갑주, 보물 사냥꾼.

자원은 **분노**입니다. 시간이 지나면 차오르고, 적을 때리거나 맞으면 더 빨리 찹니다.

### 아이템
- 장비 칸 10개: 무기, **방패**, 투구, 목걸이, 갑옷, 반지 2, 장갑, 허리띠, 장화
- 희귀도: **일반**(흰색) · **마법**(파랑, 속성 1–2개) · **레어**(노랑, 속성 3–6개, 무작위 이름) · **세트**(초록, 3세트 13종) · **유니크**(황금색, 36종)
- 기본형 73종 (단검·소검·곤봉·대형 망치·보병 도끼·츠바이헨더·거인의 망치 등 무기 24종, 방패 8종, 방어구 41종)
- **양손 무기**(대형 망치, 쌍날 도끼, 대검, 츠바이헨더 …)는 피해가 크고 사거리가 길지만 방패를 들 수 없습니다. 방패는 근접 공격과 투사체를 **막기**(피해 0)할 확률을 줍니다
- 접두사/접미사 32종: 화염·냉기·번개 추가 피해, 언데드 추가 피해, 받는 피해 감소, 처치 시 생명력·분노, 재사용 대기시간 감소, 분노 소모 감소, 물약 회복량, 막기 확률, 원소 저항, **특정 스킬 레벨 +1~2** 등
- 세트: 부족장의 유산(4), 서리 늑대의 맹세(4), 고대 왕의 갑주(5). 여러 개를 함께 입으면 2·3·4·5세트 효과가 붙습니다
- 강화된 장비는 이름 앞에 +N이 붙습니다
- 착용한 투구·갑옷·장갑·장화·무기·방패가 캐릭터 그림에 그대로 보입니다
- 요구 레벨이 있어 너무 좋은 장비는 레벨을 올려야 착용할 수 있습니다

### 드롭: 적당히, 대신 깊을수록 좋게
몬스터는 많이 나오지만 아이템은 너무 많이 쏟아지지 않도록 한 마리당 드롭을 낮췄습니다 (한 층에 대략 8–14개).

| 대상 | 아이템 | 그 밖에 |
| --- | --- | --- |
| 일반 몬스터 | 4% 확률로 1개 | 골드 14%, 물약 4.5% |
| 챔피언(파란 기운) | 45% 확률로 1개 | 골드 70% |
| 정예(황금 기운, 이름 있음) | 2개, 하나는 마법 이상 | 골드, 물약 60% |
| 보스 | 3개, 하나는 레어 이상 | 골드, 물약 |
| 보물 상자 | 1–2개 | 골드 |

층이 깊어질수록 몬스터 레벨이 오르고 희귀도 확률이 올라갑니다. 일반 몬스터가 아이템을 떨어뜨렸을 때의 희귀도 분포(마법 아이템 발견 0% 기준):

| 몬스터 레벨 | 일반 | 마법 | 레어 | 유니크 | 세트 |
| --- | --- | --- | --- | --- | --- |
| 1 | 71% | 29% | 0% | 0% | 0% |
| 3 | 62% | 31.6% | 5.4% | 0.6% | 0.3% |
| 6 | 56% | 35.2% | 7.8% | 0.8% | 0.5% |
| 10 | 47% | 40% | 11% | 1.2% | 0.7% |
| 15 | 36% | 46% | 15% | 1.7% | 0.9% |
| 20 | 26% | 52% | 19% | 2.2% | 1.2% |

챔피언은 유니크·세트 확률 3배, 정예는 5배, 보스는 10배입니다. 유니크·세트·레어가 떨어지면 빛기둥과 효과음으로 알려 줍니다. 바닥 아이템 표시 필터(L 키, 메뉴)로 일반·마법 아이템 이름을 숨길 수 있습니다.

### 던전 (50층, 엔딩 있음)
- 매 층 무작위 생성, 탐험한 곳만 보이는 시야와 미니맵
- **1–19층은 지하** (방 + 통로), **20층부터는 탁 트인 바깥 지역**: 숲으로 둘러싸인 넓은 공터들을 굽은 큰길이 잇고, 공터 안에는 바위·나무 무더기, 버려진 야영지(모닥불), 돌기둥 폐허, 무덤, 불타는 땅이 흩어져 있습니다. 시작점에서 계단까지는 흙길이 나 있습니다
- 13가지 테마: 어둠의 묘지(1) → 망자의 동굴(4) → 버려진 성채(7) → 불타는 심연(10) → 혼돈의 성역(13) → 얼어붙은 지하묘지(16) → 역병의 늪지(20) → 핏빛 황야(25) → 잿빛 황무지(30) → 그림자 숲(35) → 불타는 평원(40) → 얼어붙은 설원(45) → **망자의 왕좌(50)**
- 바깥 지역은 Flare 풀밭 타일에 테마마다 색을 입혀(필터) 늪·황야·잿빛 땅·밤의 숲·불타는 들판·눈밭으로 보이게 했습니다
- **50층이 마지막 층**입니다. 최종 보스 '망자의 왕 오르쿠스'를 쓰러뜨리면 엔딩과 함께 이번 모험의 기록(걸린 시간, 레벨, 처치 수, 쓰러진 횟수 등)이 나옵니다. 엔딩 뒤에도 웨이포인트로 아무 층(50층 포함)에 가서 계속 사냥할 수 있고, 타이틀에는 '정복 완료'가 표시됩니다

### 악몽 난이도 (엔딩 뒤)
일반 난이도에서 망자의 왕을 쓰러뜨리면 **악몽**이 열립니다. 엔딩 화면의 **악몽 난이도 도전** 버튼이나, 마을 **심연의 문** 창 위쪽의 일반 / 악몽 탭으로 바꿉니다.

| | 일반 | 악몽 |
|---|---|---|
| 몬스터 레벨 | 1층 1 → 50층 75 | 1층 48 → 50층 97 |
| 정예 | | 정예 무리 1개 더, 이름 있는 정예는 특성 1개 더 |
| 보상 | | 마법 아이템 발견 +60%, 골드 1.5배, 높은 아이템 레벨 |
| 불리한 점 | | 모든 원소 저항 -20% |

- 캐릭터·장비·보관함은 그대로이고, 층과 웨이포인트는 1층부터 다시 엽니다 (난이도마다 따로 기억)
- 다른 난이도로 바꾸면 열려 있던 귀환 차원문은 닫힙니다
- 악몽 50층의 망자의 왕을 쓰러뜨리면 악몽 엔딩이 나오고, 타이틀에 '악몽 정복'이 표시됩니다
- 층마다 등장 가능한 몬스터 중 4–6종을 골라 층마다 분위기가 달라집니다
- 한 층에 몬스터 약 160–210마리 (1층은 약 90마리로 시작해 5층까지 점점 늘어남). 방(공터)마다 큰 무리가 1–4개, 통로(길)에도 떠도는 무리가 있습니다
- 5층마다 보스가 계단을 지키며, 보스를 쓰러뜨려야 다음 층으로 내려갈 수 있습니다

### 몬스터와 공격 패턴 (일반 26종 + 보스 10종)

깊은 층의 새 몬스터 일부는 Flare 원작처럼 같은 그림에 색을 입혀(color_mod) 만든 변종입니다.

| 몬스터 | 등장 | 공격 패턴 |
| --- | --- | --- |
| 좀비 · 해골 창병 · 해골 석궁병 | 1층~ | 근접 / 화살 |
| 고블린 무리 | 1층~ | 떼로 몰려오고, 체력이 낮으면 도망 |
| 해골 마법사 | 고블린 무리와 함께 | 화염구, 쓰러진 동료를 **되살림** |
| 새끼 개미귀신 | 2층~ | 땅속에 숨어 있다가 가까이 오면 떼로 **솟아오름** |
| 홉고블린 · 홉고블린 궁수 | 3층~ | 방패로 앞쪽 공격을 **막음** / 세 번째마다 화살 3발 **일제 사격** |
| 저주받은 무덤 | 3층~ | 움직이지 않고 해골 병사를 계속 **불러냄** (부수면 멈춤) |
| 개미귀신 | 4층~ | 땅속으로 **파고들어** 발밑에서 튀어나옴, 흡혈 |

## 그래픽

캐릭터, 몬스터, 던전 타일, 아이콘은 **Flare: Empyrean Campaign** 프로젝트의 무료 스프라이트입니다. 디아블로풍 3D 프리렌더 그림으로, 8방향 애니메이션이 있습니다.

- **야만용사**: 웃통을 벗은 기본 몸 위에 머리·몸통·다리·손·발·무기 레이어를 겹쳐 그립니다. 가죽/사슬/판금 장비를 착용하면 그 모습으로 바뀝니다. 무기 종류(손도끼, 쌍날 도끼, 장검, 대검, 철퇴, 전쟁 망치)도 그대로 보입니다.
- **몬스터**: 위 표의 36종 모두 Flare 그림입니다(폭풍 비룡, 광차 고블린, 거대한 폭풍의 비룡왕 포함). 대기·달리기·공격·죽음 동작이 있고, 매복하는 몬스터는 땅에서 솟아오르는 동작도 있습니다.
- **마을**: Flare 풀밭 타일셋의 풀밭·돌길·나무·천막·모루·모닥불·상자·묘비와 빛나는 돌 원, NPC 그림(대장장이, 약초상, 상인, 고블린 행상, 기사, 주민, 오벨리스크)
- **방패**: 버클러, 둥근 방패, 철 버클러, 카이트 방패 레이어가 캐릭터 그림에 보입니다
- **던전**: 석재 던전과 동굴 타일셋. 테마마다 색을 입혀 성채(초록), 불타는 심연(붉은색), 혼돈의 성역(보라)을 만듭니다. 방 앞쪽 벽은 디아블로처럼 낮게 잘라 그려서 방 안이 가려지지 않습니다.
- **소품**: 벽걸이 횃불, 화로, 가시 달린 보물 상자, 계단 구덩이, 뼈 무더기
- **아이콘**: 아이템과 스킬 아이콘
- **스킬 효과**: 휘두를 때 칼날 궤적, 도약 착지 지진, 대지 분쇄의 솟아오르는 가시, 함성·광폭화의 주황 고리, 회전하며 날아가는 도끼, 화살, 화염구와 폭발, 얼음창, 독침, 마력구, 연쇄 번개의 낙뢰, 소환 마법진, 순간이동 어둠 안개, 차원문 룬, 타격 불꽃, 물약·레벨업 빛
- 조명, 피 튀김, 화면 흔들림, 피해 숫자는 코드로 그립니다.

### 효과음

Flare 효과음 86개를 씁니다: 휘두르기, 함성, 지진, 가시, 화염, 번개, 물약, 레벨업, 금화, 장비 종류별 착용 소리, 방패 막기, 상자, 계단, 발소리, 체력이 낮을 때 심장 박동, 몬스터마다 다른 공격·피격·죽음·발견 울음, 무덤 소리, 순간이동·차원문, 상인 목소리, 배경음(던전 물방울, 동굴 바람, 마을 새소리). 효과음 파일을 아직 불러오지 못했으면 즉석 합성한 소리로 대신합니다.

그림을 아직 불러오지 못했거나 불러오기에 실패하면, 이전 버전의 코드로 그린 그림으로 대신 표시합니다.

### 그림 자원 다시 만들기

`assets/flare/`의 그림은 Flare 원본에서 필요한 프레임만 골라 70% 크기의 WebP 아틀라스로 다시 묶은 것이고, 효과음은 MP3로 바꿔 `sounds.js`에 담았습니다(합계 약 33MB). 처음에는 타일, 기본 몸, 마을 사람, 1층 몬스터, 효과 그림만 불러오고 나머지는 그 층에 들어갈 때 불러옵니다. 효과음 변환에는 `ffmpeg`가 필요합니다. 일부 몬스터·NPC(홉고블린, 어둠의 망자, 해골 기사·대마법사·왕, 갑각 개미귀신, 고블린 행상)는 같은 저장소의 `mods/empyrean_campaign`에서 가져옵니다.

```
git clone --depth 1 https://github.com/flareteam/flare-game.git
python3 -I tools/build_flare_assets.py flare-game/mods/fantasycore assets/flare
```

몬스터나 장비 레이어를 더 넣으려면 `tools/build_flare_assets.py` 위쪽의 목록에 이름을 추가하고 다시 실행하면 됩니다.

## 파일 구조

```
index.html        화면 구성 (HUD, 패널, 오버레이)
assets/flare/     Flare 스프라이트 아틀라스(WebP), manifest.js(프레임 좌표), 저작자 표시
tools/build_flare_assets.py  Flare 원본 → 게임용 아틀라스 변환
css/style.css     UI 스타일
js/util.js        공통 함수, 아이소메트릭 좌표 변환
js/data.js        스킬, 아이템 기본형, 접두사/접미사, 유니크, 세트, 몬스터, 보스, 테마, 비약 데이터
js/items.js       아이템 생성, 희귀도 굴림, 툴팁
js/dungeon.js     던전 생성, 충돌, A* 길찾기, 시야
js/assets.js      Flare 그림 불러오기, 8방향 애니메이션, 장비 레이어, 아이콘
js/sprites.js     코드로 그린 캐릭터 (그림을 못 불러왔을 때 대신 사용)
js/icons.js       코드로 그린 아이콘 (위와 같음)
js/effects.js     파티클, 피해 숫자, 바닥 흔적
js/entities.js    몬스터 생성·AI, 전투, 전리품, 투사체, 독 웅덩이
js/monsterai.js   몬스터 특수 행동 (돌진, 땅굴, 매복, 소환, 급강하, 순간이동, 되살리기 …)
js/town.js        마을 지도, 주민, 상점·강화·도박·재련·보관함, 귀환 차원문, 웨이포인트
js/player.js      능력치 계산, 이동, 스킬, 소지품, 레벨업 카드
js/render.js      타일·벽 깊이 정렬, 조명, 오버레이
js/ui.js          HUD, 소지품/캐릭터 창, 카드 선택
js/audio.js       효과음 합성
js/game.js        게임 루프, 입력, 층 이동, 저장
```

데이터 수정은 대부분 `js/data.js`에서 할 수 있습니다. 예를 들어 새 유니크를 추가하려면 `UNIQUES` 배열에 한 줄을 넣으면 됩니다.
